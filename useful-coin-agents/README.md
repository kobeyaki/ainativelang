# Useful Coin — AINL Agent System

AINL-powered marketing automation for Useful Coin (`$USEFUL`).
Coordinates 8 Agency agents as a compiled deterministic graph — not prompt loops.

## Programs

### `content-calendar.lang`
Generates a rotating 7-day content plan across X, Reddit, and TikTok.
- Themes: mascot lore, community wins, meme formats, "nothing can stop us"
- Cache-aware: skips regeneration if plan is < 24h old
- Maps each day to the right agent: whimsy-injector, tiktok-strategist, growth-hacker, content-creator, brand-guardian, image-prompt-engineer, reddit-community-builder
- **Cron:** `0 6 * * *` (6 AM daily)

### `social-monitor.lang`
Monitors Useful Coin mentions every 15 minutes.
- Deduplicates via cache (last-seen timestamp)
- Persists new mentions to `useful-coin.db` (SQLite)
- Queues an alert to the `alerts` queue if engagement spikes (> 5 new mentions)
- **Cron:** `*/15 * * * *`

### `growth-loop.lang`
Picks today's content task from the calendar and routes to the right agent.
- Routes: growth-hacker (experiments), image-prompt-engineer (visuals), content-creator (copy)
- Throttled: only runs once per hour via cache check
- Caches result for orchestrator to read
- **Cron:** `0 9 * * *` (9 AM daily)

### `brand-check.lang`
HTTP API endpoint — validates content before it goes out.
- Flags: price talk, "guaranteed", "will moon", "100x"
- Returns `{"status":"approved"}` or `{"status":"flagged","reason":"..."}`
- Call via: `POST /brand-check/check` with `{"content": "your post text"}`
- Use before posting anything generated by agents

### `orchestrator.lang`
Master daily workflow — runs everything in sequence.
- calendar → social → growth loop → daily summary
- Graceful error handling (falls back to cached state if sub-step fails)
- Pushes daily summary to `daily_summary` queue
- **Cron:** `0 7 * * *` (7 AM daily, before growth-loop fires)

## Running

```bash
VENV=/data/.openclaw/workspace/ainl-venv
AINL_DIR=/data/.openclaw/workspace/skills/ainativelang
PROGRAMS=/data/.openclaw/workspace/useful-coin-agents

# Validate all
for f in content-calendar social-monitor growth-loop brand-check orchestrator; do
  PYTHONPATH=$AINL_DIR $VENV/bin/ainl-validate $PROGRAMS/$f.lang
done

# Run orchestrator
cd $AINL_DIR && $VENV/bin/ainl run $PROGRAMS/orchestrator.lang --json

# Run individual programs
cd $AINL_DIR && $VENV/bin/ainl run $PROGRAMS/content-calendar.lang --json
cd $AINL_DIR && $VENV/bin/ainl run $PROGRAMS/social-monitor.lang --json
cd $AINL_DIR && $VENV/bin/ainl run $PROGRAMS/growth-loop.lang --json
```

## Token Cost Savings vs Prompt Loops

| Approach | Cost per daily run |
|---|---|
| Prompt loop (8 agents, full context each) | ~40-80k tokens |
| AINL orchestrator (compiled graph, adapter calls) | ~2-5k tokens |
| **Savings** | **~90-95%** |

AINL compiles intent into a deterministic graph. At runtime, the graph executes adapter calls (cache, SQLite, queue, social) without re-prompting a model for routing logic. The model is only called when an agent adapter (`R agent send_task ...`) fires — and only for that specific subtask with a tight prompt.
