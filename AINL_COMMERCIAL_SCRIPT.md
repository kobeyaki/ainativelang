# AINL Viral Commercial - 90 Second Script

**Title:** "The Orchestration Compiler"  
**Duration:** 90 seconds  
**Style:** Professional, cinematic, institutional  
**Music:** Subtle build (tension → resolution)

---

## ACT 1: Problem (0-15 seconds)

**Visual:**
- Engineer at desk, frustrated, typing frantically
- Split screen: code on left (loop after loop), face on right
- Color: Red/warm (problem state)
- Zoom on code loops

**Voiceover:**
"You're spending $1,183 a year on orchestration you don't need."

*[Pause]*

"Every decision. Through the LLM. Again."

*[Sound effect: frustrated typing, then STOP]*

---

## ACT 2: Solution (15-40 seconds)

**Visual:**
- Clean transition (fade to black, then fade up)
- AINL code snippet appears (agent.lang graph)
- Smooth, minimal, organized
- Color shift to cool blues/greens (solution state)
- Terminal showing: `ainl compile agent.lang`
- Checkmarks appearing: ✓ Parsing ✓ Validating ✓ Compiling
- Dashboard fade in: clean metrics display

**Voiceover:**
"What if orchestration wasn't the LLM's job?"

*[Transition sound: soft chime]*

"What if it was compiled instead?"

*[Sound: satisfying whoosh as dashboard appears]*

## Production Notes

**Color Palette:**
- Red/Orange (#ff4444): Problem state (Act 1)
- Dark/Blue (#0d1117, #1e1e1e): Neutral base (Acts 2-4)
- Green (#00dd00): Solution/success (Acts 2-3)
- Cyan (#4ec9b0): Accents and highlights

**Sound Design:**
- Act 1: Typing sounds, frustration, STOP (tension)
- Act 2: Transition chime, whoosh, satisfying sounds (revelation)
- Act 3: Ascending tone, triumphant (proof)
- Act 4: Resolving chord, fade (completion)

**Transitions:**
- 1→2: Fade to black (0.5 sec) then fade in
- 2→3: Dissolve (1 sec)
- 3→4: Slow fade (1.5 sec)

**Music:**
- Subtle electronic/minimal
- Builds from Act 1 to climax in Act 3
- Resolves in Act 4
- Volume: -20dB (doesn't overpower voiceover)

**Typography:**
- Title font: Bold, institutional
- Numbers: Large, high contrast
- GitHub link: Monospace, easy to read
