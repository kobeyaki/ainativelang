# YouTube Short #1 - "90% Cheaper"

**Duration:** 30 seconds  
**Format:** Vertical (9:16 aspect ratio for Shorts)  
**Hook:** Cost comparison ($1,183 → $130)  
**Visual:** Dashboard + scrolling through savings breakdown

---

## Script

**0:00-0:05 (Hook)**
Visual: Red text "$1,183" on black background, then green text "$130" slides in
Voiceover: "Your AI agent framework costs $1,183 per year."

**0:05-0:15 (Problem)**
Visual: Dashboard showing Traditional cost breakdown
  - 4,500 tokens per run
  - 1,440 runs/day
  - $6/day
Voiceover: "Orchestration loops. Every decision goes through the LLM."

**0:15-0:25 (Solution)**
Visual: Dashboard flips to AINL side
  - 487 tokens per run
  - 1,440 runs/day
  - $0.35/day
Voiceover: "We compile it instead. LLM only at decision nodes."

**0:25-0:30 (CTA)**
Visual: Green check mark + GitHub link (github.com/sbhooley/ainativelang)
Voiceover: "90% savings. Open-source. Link in bio."

---

## Voiceover Text (for TTS)

"Your AI agent framework costs $1,183 per year. Orchestration loops. Every decision goes through the LLM. We compile it instead. LLM only at decision nodes. 90% savings. Open-source. Link in bio."

---

## Visual Design

**Background:** Dark (#0d1117)  
**Numbers:** Large, bold, high contrast  
**Colors:**
- Red: $1,183 (problem)
- Green: $130 (solution)
- Accent: Cyan (#4ec9b0) for logos/highlights

**Aspect Ratio:** 1080x1920 (vertical)  
**Text:** Large, readable at phone size  
**Pacing:** Fast transitions (snappy, scrollable feel)
